**Button** — the LinX pill CTA: uppercase, letter-spaced, gold. Use for every primary and secondary action.

```jsx
<Button variant="primary">Post a Project Free</Button>
<Button variant="outline-gold">Join as Contractor</Button>
<Button variant="outline" size="sm">Refresh</Button>
```

Variants: `primary` (solid gold), `outline-gold` (black w/ gold border, inverts to solid gold on hover), `outline` (neutral border, warms to gold on hover). Sizes: `sm` `md` `lg`. Pass `href` to render an `<a>`, `block` for full width.
