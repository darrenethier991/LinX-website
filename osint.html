LINX Recon · passive public observations

Review public signals, not private systems.

LINX Recon provides a bounded, no-login review of a public domain you own or are authorized to assess. It reads public RDAP metadata, DNS-over-HTTPS answers, and one unauthenticated HTTPS response header. It does not submit forms, run page scripts, test credentials, scan ports, or retain a scan history.

◇
Authorized use only. Use this tool only for domains you own or are explicitly authorized to assess. Results are technical observations, not a fraud determination or security certification.
